# AI 自然语言生成与命令续写

管理端提供兼容 Chat Completions 的服务地址、模型、加密 API Key、启用状态、结构分享和超时配置。管理员与普通账号通过各自认证入口调用。密钥仅由后端解密使用，AI 请求与响应正文不进入审计预览。

SQL/命令编辑器支持输入停顿后的行内续写，以及 Cmd/Ctrl+I 将选中内容或当前行的自然语言转换为 SQL/Shell。生成不执行，支持撤销；取消、切换资源和继续编辑均不会被旧响应覆盖。SSH 终端使用独立命令草稿，复制后由用户操作终端。
