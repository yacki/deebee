# 表格选中、定位与表头滚动优化

2026-10-21，Australia/Perth。已更新到 https://deebee.idmesh.site/deebee/ ，刷新工作台生效。

## 行为

- 单击单元格即显示稳定的 2 像素实线边框，当前行、行号和列头同步标识。悬停其他位置、重复点击和打开右键菜单不覆盖当前选中反馈。
- 行号支持单行、Cmd/Ctrl 多行和 Shift 连续行选择；右键保持已有选择范围。“取消全选”同时清除当前单元格和数据页删除目标。
- 方向键、PageUp/PageDown、Home/End、Ctrl/Cmd+Home/End、Tab/Shift+Tab 定位单元格；F2/Enter 编辑可写单元格，保存后焦点回到表格。原有主键保护保留。
- 表头与数据滚动区分开，纵向滚动条从表头下方开始；横向滚动条固定在数据区底部。表头与数据使用同一列宽，横向滚动直接同步位置。行号与冻结列在两个区域按相同偏移固定。
- 使用独立边框，去掉表格单元格过渡，并关闭数据区的浏览器滚动锚定。滚轮悬停在表头时仍能滚动数据区。
- 每个结果在切换 Tab 后恢复自己的当前单元格、选中行、横纵滚动位置、行高和冻结列。视图状态以结果数组为 WeakMap 键保存在内存中，不把结果数据加入草稿保存，关闭标签或替换结果后可以回收。

## 验证

先在此前发布包上新增两项检查，均复现失败：查询结果缺少稳定的单元格选中状态、表头没有独立于滚动区。修复后最终 **48 项不同浏览器用例通过**，其中 7 项是本次新增的选择、键盘、滚动定位、标签恢复与删除目标检查。10 项 Node 测试、TypeScript/Vite 生产构建、Lint、差异检查通过。

主要检查包括：

- 7000 行末行编辑及正确主键、离屏前保存、跳转、24/60 像素行高、冻结列、窗口缩放和完整打印准备。
- 点击、悬停、重复点击、滚动离屏再返回和右键后，当前单元格及选中行保持一致。
- 滚动到 4500 像素后，第 151 行坐标与数据区顶部一致；等待后 scrollTop 不发生补偿位移。横向滚动后表头与数据列坐标差小于 1 像素。
- 切换 Tab 后恢复选中位置及 scrollTop/scrollLeft；原草稿恢复与自动保存边界保留。
- 数据页取消选择后禁用删除；右键选择第二行后，删除请求只针对其原主键。
- 对象目录、UI 控件、SSH/RDP 导航和 RDP 认证/重试专项。

多选测试使用 macOS 的 Cmd 点击，避免将该平台 Ctrl 点击的原生右键行为当作多选。实际浏览器工具另用独立本地 HTTP 服务和 7000 行模拟数据检查了点击、滚轮和最终外观，未操作生产业务数据。截图：`/tmp/deebee-grid-interaction-20261021.png`。物理打印不在本次实机验证范围，打印测试核对准备阶段包含全部数据行。

同机生产包、完整模拟接口返回 7000 行和 24 列的最终结果：查询显示 **279.5 ms**，三次切 Tab **73.6 / 61.8 / 62.9 ms**，正常视口挂载 32 行（扩大了离屏预留，未减少结果条数）。这是浏览器验收基准，不代表生产数据库执行耗时。
