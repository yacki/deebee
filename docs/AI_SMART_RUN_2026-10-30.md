# 直接运行自然语言

在原有 SQL／命令编辑器中输入自然语言，使用原有运行按钮或 Cmd/Ctrl+Enter。原生 SQL 直接走现有执行路径；自然语言由 `/api/ai/prepare` 或普通账号 `/api/v1/ai/prepare` 生成代码，服务端独立解析判断是否可自动运行。

单条 SELECT/集合查询可自动运行。多语句、写入、锁、导出文件、变量、副作用函数及未知函数不会自动运行；服务器命令一律确认。写入确认使用原有执行与审批入口，不自动切换高权限访问方式。普通账号保留当前资源账号、CSRF 和授权边界。

需求原文保留，实际代码可展开查看、放入编辑器或复制。缺少对象时原位补问；取消、修改输入、切换资源/数据库/访问方式均使旧响应失效。原来的 Cmd/Ctrl+I 保留为“仅生成”。自然语言不再触发行内续写。

前端构建和隔离暂存源码构建通过；89 项后端测试和 37 项 Node 测试通过。浏览器覆盖一键运行、原生 SQL、写入确认、补问、错误、关闭、重复快捷键、旧响应、数据库切换以及普通账号的查询和 SSH 审批路径。原有 21 项 SQL 补全测试通过。

发布沿用上次验证的镜像，后端仅更新 `ai.py` 并新增 `ai_run.py`。前端延续已上线工作区基线，精确源文件、lockfile、产物与哈希清单保存在发布目录；本次功能提交不包含此前其他未提交的 UI/性能变更。发布前备份配置和数据，仅切换 DeeBee 服务；失败自动回滚。远程验收使用常量 SELECT，写入场景只验证生成和等待确认，不执行修改。
