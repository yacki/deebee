## 兼容与图标来源

用户组沿用原有内部 `roles` / `role_id` / `role-memberships` 标识，已有成员、授权及配置导入导出保持兼容。环境继续使用资源上的 `environment` 字段，作为分类维度。

图标采用 [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0)，固定提交 `54cfe13ac10eaa1ef817a343ab0a9437eb3c2e08`，九个 SVG 随应用打包，无运行时 CDN。原 MIT 许可证和具体文件来源保留在 `src/assets/resource-icons/`。

复现界面测试：启动使用临时 `DEEBEE_ACCESS_DIR` 的本地后端，将 Vite 的 `DEEBEE_API_PROXY` 指向它，再执行 `DEEBEE_GROUP_UI_URL=http://127.0.0.1:15173 npx playwright test tests/e2e/user-groups-environments.spec.ts --workers=1`。该测试仅接受回环地址，并会创建测试资源、用户组和人员，应始终使用独立数据目录。
