# SSH 文件管理开发与验收

日期：2026-10-26（Australia/Perth）

## 功能

- 管理员工作台左侧 SSH 主机右键菜单新增“文件管理”，独立弹窗，不必先打开终端。
- 左侧按需加载目录树，右侧文件列表；显示类型、大小、修改时间、权限和符号链接。
- 支持路径跳转、上级/主目录、刷新、文件名筛选、隐藏文件、排序和多选。
- 支持批量文件上传和下载，远程文件/文件夹移动、重命名、新建目录及确认删除。
- 支持本地文件拖放上传、远程条目拖到目录树移动。
- 上传与下载显示进度和记录；上传使用临时文件，完成后发布目标名称；失败清理临时文件。
- 上传和移动拒绝覆盖已有目标；阻止根目录变更和目录移入自身；递归删除不跟随符号链接。
- 使用现有管理员身份、已保存的 SSH 配置及主机指纹校验；不扩展普通授权用户权限。

## 当前边界

- 目标 SSH 服务需要启用 SFTP，操作受该远程账号实际文件权限约束。
- 单文件上限 2 GB；下载经浏览器缓冲后保存，实际可用大小受浏览器内存限制。
- 暂不支持文件夹整体上传/下载、断点续传或覆盖已有文件。
- 移动使用 SFTP rename，跨文件系统移动受远端服务器限制。
- 取消上传表示停止等待结果，远程写入可能已经完成；界面提示刷新核实。
- 初次验收为本地开发与隔离环境验证；随后按用户指令提交、推送并执行远程部署，状态见下文。
